## ⚡ البدء السريع (5 دقائق)

### 📋 الخطوات الأساسية:

```bash
# 1️⃣ انتقل للمجلد
cd ai-mikrotik-platform

# 2️⃣ اقرأ دليل البدء السريع
cat QUICK_START.md

# 3️⃣ شغّل Backend
cd backend
pip install -r requirements.txt
python -m app.main

# 4️⃣ شغّل Frontend (في terminal جديد)
cd frontend
npm install
npm run dev

# 5️⃣ افتح المتصفح
# http://localhost:5173
```

## 🔑 المتطلبات الأساسية

### 1. مفاتيح API (إلزامية):
```env
OPENAI_API_KEY=sk-...
GEMINI_API_KEY=AI...
```

**كيف تحصل عليها؟**
- **OpenAI**: https://platform.openai.com/api-keys
- **Gemini**: https://makersuite.google.com/app/apikey

### 2. معلومات الراوتر (إلزامية):
```env
MIKROTIK_HOST=192.168.88.1
MIKROTIK_USERNAME=admin
MIKROTIK_PASSWORD=your-password
```

### 3. Python & Node.js:
- Python 3.11+
- Node.js 18+
- npm أو yarn
